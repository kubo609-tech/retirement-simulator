# 退職後資産シミュレーター

給与・退職一時金・DC(確定拠出年金)年金・個人年金・公的年金の受け取りと、税金・生活費を踏まえた「現金」「運用資産」の年次推移を試算する、単一HTMLファイルのインタラクティブダッシュボードです。

外部ライブラリ・ビルド環境は一切不要の単一HTMLファイルです。下記のURLをブラウザで開くだけで動作します。

**<https://kubo609-tech.github.io/retirement-simulator/>**

入力値はすべてお使いのブラウザ内(`localStorage`)だけに保存され、サーバーへは一切送信されません。初期値は空欄なので、ご自身の数値を入力してご利用ください。

### スマートフォン・タブレットで使う場合

必ず上記のURLから開いてください。HTMLファイルをダウンロードしてFilesアプリ等からタップして開くと、iOS/iPadOSでは**Quick Lookプレビュー**に回され、**JavaScriptが実行されません**。この場合、画面は表示されるもののボタンが反応せず、グラフも描画されません(iPadのChrome・Safariとも同じ挙動です)。

## 主な機能

- **収入源の個別設定**(すべて年齢ベース)
  - 給与(60歳前後などで2段階の年収を設定可能)
  - **退職後の少額収入**(年額・開始年齢・継続年数):再雇用終了後の副業やアルバイトなどを想定した収入です。開始年齢の初期値は「退職年齢」と同じ値になります。給与所得として、他の給与と合算して給与所得控除・総合課税を適用します
  - 退職一時金(受取り年齢・勤続年数・受取り時の現金配分比率を個別に設定)
  - DC(確定拠出年金)年金(総額・受取り開始年齢・受取り年数)
  - 個人年金(年金総額・受取り開始年齢・受取り年数):民間の個人年金保険などを想定した収入です。DC年金と同じく、総額÷受取り年数を受取り開始年齢から受取り年数分だけ毎年の収入に計上し、公的年金等控除の対象・総合課税の雑所得として簡易計算します
  - **公的年金**(本人・パートナーそれぞれ**老齢基礎年金・老齢厚生年金を分けて入力**・受給開始年齢):年次内訳・グラフでは合算した「公的年金」として表示しますが、厚生年金の内訳は遺族厚生年金の計算に使用します。既定値は「本人=元会社員(基礎80万円+厚生120万円)、パートナー=専業主婦等(基礎80万円+厚生0円)」という夫婦を想定した値です
  - **パートナーの年金**(本人との年齢差・パートナー自身の受給開始年齢)。年齢差はパートナーが年上なら+、年下ならマイナスで入力し(パートナーの年齢=本人の年齢+年齢差)、受給開始年齢はパートナー自身の年齢で指定します。パートナーが本人より先に受給を始めるケースにも対応
  - **公的年金の繰上げ・繰下げ自動調整**(チェックボックスでON/OFF、既定ON):老齢基礎年金・老齢厚生年金の合計額を65歳から受け取る場合の額とみなし、受給開始年齢に応じて年額を自動で増減させます(繰上げ=1ヶ月あたり **-0.4%**・最大-24%、繰下げ=1ヶ月あたり **+0.7%**・最大+84%)。パートナーの年金にも同じロジックを適用し(パートナー自身の受給開始年齢で判定)、調整後の年額はサイドバーにその場で表示されます
  - **加給年金**(チェックボックスでON/OFF、既定OFF):本人の厚生年金加入期間が20年以上ある(受給要件チェックボックスで指定)前提で、本人の年金受給中にパートナーが65歳未満の間、本人の公的年金に加給年金額(年額・既定40万8,100円・概算、編集可)を上乗せします。パートナーが65歳になった時点で自動的に打ち切ります。子の加算・振替加算・在職老齢年金による支給停止は対象外です
  - **死亡・遺族厚生年金**(「死亡・遺族年金」欄、チェックボックスでON/OFF、既定OFF):本人・パートナーそれぞれに死亡年齢を設定でき、指定した年齢に達した年から、その人の給与・退職後の少額収入・退職金・DC年金・個人年金・公的年金(加給年金含む)をすべて0として試算します。「遺族厚生年金を計算に含める」をONにすると、生存側は**自分の老齢基礎年金・老齢厚生年金を全額受け取ったうえで**、「死亡した人の老齢厚生年金額の**3/4**」と「(死亡した人+生存側自身の老齢厚生年金額の合計)の**1/2**」のいずれか高い方から生存側自身の老齢厚生年金額を差し引いた差額を、遺族厚生年金として**非課税**で上乗せします(併給調整)。死亡した人が**「厚生年金加入期間が25年以上ある(遺族厚生年金の発生要件)」**にチェックが入っている場合のみ発生するため、本人=元会社員(既定ON)・パートナー=専業主婦等(既定OFF)という組み合わせでは、本人死亡時のみパートナーに遺族厚生年金が発生し、パートナー死亡時は本人の年金額に変化がない(妻の年金分がまるまる消える)という非対称な結果になります。本人・パートナーの両方が死亡した年より後は試算を打ち切ります。中高齢寡婦加算(現行制度では妻のみ対象)、65歳以降の受給調整の細部、遺族基礎年金(子がいる場合)は非対応です
- **税額の概算計算**(令和8年/2026年分の税制を簡易適用)
  - 給与所得控除・公的年金等控除・基礎控除・所得税速算表・住民税(10%+均等割)
  - 退職一時金は分離課税・1/2課税、DC・個人年金・公的年金は総合課税の雑所得として計算
  - パートナーの年金は、本人とは別世帯主体として個別に確定申告する前提で課税額を計算(合算した1人分の申告として扱うと税率が過大になるため)
  - 左パネル右上の「税率を確認」ボタンから、計算に使用している所得税速算表・給与所得控除・公的年金等控除・基礎控除・退職所得控除・社会保険料控除/医療費控除/配偶者控除・NISA運用益課税率(現在の設定値)をモーダルでまとめて確認できます
- **社会保険料控除・医療費控除・配偶者控除**(左パネル「社会保険料・追加控除」欄でON/OFF、既定ON)
  - **社会保険料(健康保険・介護保険料等)**:現役時代は給与に対する概算料率(既定15%)、退職後(給与終了後)は年額(既定40万円、支出上昇率で調整)で概算。**税額控除としてだけでなく、実際の支出としても収支に反映**されます(年次内訳の「支出」列に内数で表示)
  - **医療費控除**:入力した年間医療費(本人+パートナー合算を想定・既定0円)から「10万円と総所得金額の5%の低い方」を差し引いた額(上限200万円)を控除。支出には計上せず、税額控除のみ
  - **配偶者控除**:「配偶者控除の対象となる配偶者がいる」にチェックを入れた場合のみ適用し(既定OFF)、既存の「パートナーの年金額」パラメータから配偶者の合計所得金額を自動判定します(所得48万円超で控除0。より複雑な配偶者特別控除は非対応)。本人の合計所得金額(900万/950万/1000万円)と配偶者の年齢(70歳以上で割増)に応じて所得税・住民税それぞれの控除額を算出
  - いずれも本人の確定申告にのみ適用し、パートナー自身の(別世帯主体としての)申告には適用していません
- **年間支出の月次内訳ポップアップ**(「支出」欄の「月次の科目別に計算する」ボタン):家賃・光熱費・通信費・食費・日用品費・自動車税・保険料・交友費・固定支出(その他)・その他の10科目について月額を入力すると、合計×12ヶ月分をその場で確認でき、「この金額を「年間支出」に反映」ボタンで年間支出欄へ書き込めます。内訳自体は保存されますが試算の計算には使用されません(年間支出を組み立てるための参考ツールです)
- **ライフステージ・リスク設定**(サイドバーの「ライフステージ・リスク設定」欄)
  - **年齢帯別の支出倍率**:年間支出(物価上昇率を適用した後の額)に、その年の年齢に応じた倍率を掛けて年間支出を算出します。初期値は **74歳まで100% / 75〜84歳 85% / 85歳以降 90%**(活動量が落ちる後期高齢期は減少し、85歳以降は医療・介護費の増加で再び上昇する一般的なパターン)
  - **スポット(一時的)支出**(最大3件):イベント名・発生年齢・支出額を登録すると、その年齢の年に一度だけ支出へ加算します。行ごとに「物価上昇率を適用する」を選べ、ONの場合は入力額を現在価値とみなして発生年までの上昇分を上乗せします。「＋ スポット支出を追加」で2件目以降を追加、各行の「✕」で削除できます
  - **年齢帯別の運用利回り(グライドパス)**(チェックボックスでON/OFF、既定ON):年齢が上がるにつれてリスク資産の比率を下げていく想定で、**〜65歳 3.5% / 66〜75歳 2.5% / 76歳以降 1.5%**(初期値)を年齢に応じて適用します。OFFにすると「資産・運用」欄の運用利回りを全年齢に一律適用します
  - スポット支出は年次内訳テーブルの「内 スポット支出」列と収入内訳グラフ(支出線上の丸印+ツールチップ)に、その年の利回り・支出倍率は資産推移グラフのツールチップに表示されます
- **NISA枠を考慮した運用益課税**
  - **「NISA枠を優先して埋める」オプション**(既定ON):運用へ回す資金は毎年、NISAの**年間投資枠(既定360万円)**と**生涯投資枠(既定1,800万円)**の空きに優先して入り、入りきらない分が特定口座になります(枠はいずれも簿価ベース、入力で変更可)。OFFにするとNISAへは新規に投資せず、全額が特定口座になります(以下2つのオプションも無効になります)
  - NISAを売却した場合、その**簿価分の生涯枠が翌年に復活**します(制度どおりの挙動)
  - 取り崩しは**特定口座から先に**行い、売却益に既定20.315%を課税。源泉徴収と同じく税引後の手取りが必要額になるよう売却額を割り戻します
  - 運用益課税は年次内訳の「税金計」に**内数(カッコ内)**として表示され、サマリーにも「内 運用益課税」を表示
  - チェックボックスでON/OFF可能(OFFにすると運用益は全額非課税として試算されます)
  - **「NISA年間枠に沿って積立」オプション**(既定OFF):ONにすると、その年のNISA年間枠に入りきらない投資資金を特定口座へ即座に回さず、現金として保有して翌年以降のNISA年間枠が空き次第優先的に投資します(退職一時金など大きな一括投資でも、特定口座を使わずNISA枠のペースで段階的に積み立てたい場合に使用)。ただしNISAの生涯投資枠を使い切った後は、通常どおり特定口座へ投資します
  - **「特定口座からNISAへ毎年移し替える」オプション**(既定OFF):ONにすると、新たに投資へ回す資金がない年でも、毎年NISA年間枠の空き分だけ特定口座を売却し、税引後の手取りをそのままNISAで買い直します(いわゆるリレー投資)。退職後で追加の入金がない場合でも生涯投資枠を使い切るまでNISAへ移していけます
    - 移し替えのための売却でその都度、含み益に対して運用益課税がかかります(その代わり、移し替えた後の値上がり分は非課税になります)
    - 現金の増減を伴わないため、投資資産の内訳グラフの「取り崩し」には含めていません(売却で支払った税額は「運用益課税」に含まれます)
- **資産管理(現金 / 運用資産の分離)**
  - 現金保有目標(円建ての固定額)を上回った分は自動的に運用へ。退職一時金の受取り時に現金へ配分した分も含め、例外なく現金保有目標ちょうどまでキャップされます
  - 「現金保有目標を下回ったら運用資産から取り崩して補充する」モード(オプション、チェックボックスで切替)
- **サマリーカード**(結果セクション上部):試算終了年齢時点の総資産・資産ピーク額・取り崩し開始年齢・**生涯収入(税引前、給与+少額収入+退職金+DC年金+個人年金+公的年金+パートナー年金+遺族厚生年金の合計)**・**生涯支出総額(インフレ加味後、生活費+スポット支出+社会保険料の合計)**・生涯納税額(概算)・内 運用益課税(概算)・運用益累計(税引前)を一覧表示。資産が枯渇する場合は資産枯渇年齢も追加表示されます
- **グラフ**(外部ライブラリ非依存、SVG自前描画)
  - 現金・運用資産の積み上げ面グラフ+合計資産ライン
  - **運用元本を点線で表示**(現金残高の上に積んだ位置に描画するため、点線と合計ラインの差がそのまま運用損益になります)
  - 「取り崩し開始年齢」「資産枯渇年齢」を自動検出してマーカー表示
  - ホバーで年ごとの詳細値(現金・運用残高・元本・運用損益・合計)を表示するツールチップ
  - **投資資産の内訳グラフ**(資産推移グラフと収入内訳グラフの間に表示):NISA枠(元本)・特定口座(元本)・運用益・取り崩し(売却手取り)・運用益課税を年齢別の積み上げ棒グラフで表示
    - NISA元本+特定口座元本+運用益=運用残高となり、二重計上なく残高を分解しています
    - 下3段(NISA元本・特定口座元本・運用益)は残高、上2段(取り崩し・運用益課税)はその年のフロー項目のため、取り崩しがあった年はバーの高さが残高よりその分高くなります
    - **取り崩し(売却手取り)**は、その年に運用資産を売却して得た手取り(売却総額-運用益課税)です。残高のすぐ上に積んでいるため、この段の下端がその年の運用残高、上端が「取り崩さなければ残っていた額」の目安になり、灰色+赤がその年に運用資産から出ていった額にあたります(NISAへの移し替えを行った年は、移し替えた元本は運用資産の中に残るため灰色には含めず、移し替えで支払った税額だけが赤に含まれます)
    - 収入内訳グラフの「取り崩し」は世帯の収支不足額(現金からの補填を含む)のため、この段の数字とは一致しません(現金だけで賄えた年はこの段は0になります)
    - 含み損(運用益がマイナス)の年は、運用益の棒は0として扱います(実際の値はホバーのツールチップで確認できます)
  - **収入内訳グラフ**(投資資産グラフの下に表示):給与・退職後の少額収入・DC年金・個人年金・公的年金(**本人・パートナーを赤系統の濃淡で色分け**、**加給年金は本人の公的年金の内数として別の色**で表示)・**取り崩し額**を年齢別の積み上げ棒グラフで表示し、**年間支出(生活費)**と**支出+保険料+税金(実質支出)**の2本の折れ線を重ねて比較できます。各年の実額は年齢間で連続変化しない(給与は退職で急に0になる等)ため、面/線グラフではなく棒グラフを使用
    - 取り崩し額 = その年の税引後収入だけでは支出を賄えなかった不足分(現金・運用資産から補填される額)。投資資産の内訳グラフの「取り崩し(売却手取り)」と同じ色(薄い灰色)で表示していますが、こちらは現金からの補填も含む世帯ベースの不足額のため数字は一致しません
    - 給与・DC年金・個人年金・公的年金の棒は税引前(額面)のため、赤字の年は棒の合計は「年間支出(生活費)」の線ではなく、生活費に社会保険料・税金を加えた「支出+保険料+税金(実質支出)」の線と一致します。2本の線の間隔がその年の社会保険料+税額に相当します
- **取り崩し時の元本の減らし方を選択可能**
  - 比例配分(平均取得単価方式):売却額を、その時点の元本と運用益の構成比で按分して元本を減らす
  - 運用益から先に取り崩す:運用益を使い切ってから元本に手をつける(元本に手をつけ始めた年齢が読み取りやすい)
  - 運用益課税がOFFなら、どちらを選んでも資産残高は変わりません(点線と運用損益の内訳表示だけが変わります)
  - 運用益課税がONの場合は実現益の出方が変わるため税額・残高にも影響します。実際の特定口座は総平均法なので、**「比例配分」のほうが実態に近い**結果になります
- **年次内訳テーブル**(年齢ごとの収入・支出・税金・残高をスクロール表示)
  - 公的年金・支出・税金計・純CF・運用残高・総資産など、複数の内訳から構成される数値にマウスオーバーすると、その内訳をツールチップで表示します。税金計は給与等分・パートナー年金分・退職金分それぞれの実効税率と、運用益課税の税率も表示します
  - 「Google スプレッドシートへ出力」を押すと、年次内訳を数値データとしてコピーして新しいGoogleスプレッドシートを開きます。開いたシートのA1へ貼り付けると列ごとに出力されます
- **入力パラメータの保存**(左サイドバーの入力値をまるごと保存)
  - 「入力内容を保存」でブラウザの `localStorage` に保存し、次回開いたときに自動で復元
  - 「保存内容を復元」で、編集途中の値を最後に保存した状態へ戻す
  - 「初期値」で全項目をHTML記載の初期値に戻す(保存データも削除。確認ダイアログあり)
  - Claude.aiのPublish済みアーティファクトとして開いている場合は、永続ストレージ(`window.storage`)にも同時保存し、読み込み時はそちらを優先
- **スマートフォン対応**(画面幅920px以下でレイアウトが切り替わります)
  - **入力グループの折りたたみ**:「基本情報」「収入・給与」などの見出しをタップで開閉できます。スマホでは既定で全グループを閉じた状態にするため、入力欄の総丈が約3,300px→約460pxになり、結果のグラフまですぐスクロールできます(PCでは従来どおり開いた状態)
  - **グラフのタッチ操作**:グラフを指でなぞると各年の詳細がツールチップで表示されます。横方向のスワイプはグラフの読み取り、縦方向のスワイプはページのスクロールに割り当てているため、スクロールを妨げません
  - グラフのSVGは描画領域の実サイズに座標系を合わせているため、画面幅にかかわらず文字が潰れたり伸びたりしません(画面の回転・リサイズ時は自動で描き直します)
  - 統計カードは2列に、入力欄は自動ズームを防ぐ文字サイズ(16px)に、チェックボックス等はタップしやすいサイズに調整されます
  - 年次内訳テーブルは横スクロールし、「年齢」列は左端に固定されます
- **ダーク/ライトモード切替**:画面右上の「ライトモード」/「ダークモード」ボタンでいつでも切替可能。選択はブラウザに保存され、次回開いたときも保持されます
  - グラフの配色を含め、画面全体がライトモード用の配色に切り替わります(グラフはCSS変数を直接参照しているため再計算不要で即座に切り替わります)
  - PDF印刷はそのとき選択中のテーマに従うため、**印刷前にライトモードへ切り替えるとインク消費を抑えられます**
- **PDFレポート出力**:画面右上の「PDFレポート出力」ボタン(またはブラウザの印刷機能)で、ブラウザ標準の印刷機能を使ってPDFに出力できます
  - 左サイドバーの入力パラメータは印刷時には非表示になり、代わりに現在の入力内容を一覧化した「入力パラメータ」サマリーが本文側に自動挿入されるため、レポート単体で内容が読めます
  - サイドバー・操作ボタン・ツールチップなど印刷に不要な要素は自動的に除外され、年次内訳テーブルはスクロール制限なしで全行印刷されます
  - 印刷ダイアログで背景色の印刷が無効化されないよう自動設定済みです(選択中のテーマの配色をそのまま出力)

## 使い方

1. <https://kubo609-tech.github.io/retirement-simulator/> をブラウザで開く
2. 左サイドバーの各パラメータを自分の状況に合わせて入力(金額欄の初期値は空欄です。空欄は0として扱われます)
3. 「シミュレーション実行」ボタンで再計算
4. 「入力内容を保存」を押すと入力値が保存され、次回同じブラウザで開いたときに自動で復元されます
5. 年次内訳の「Google スプレッドシートへ出力」を押し、開いたシートのA1に貼り付けると結果を出力できます

## 前提条件・注意点

- 税額は令和8年(2026年)分の税制を簡易的に適用した**概算**です。社会保険料控除・医療費控除・配偶者控除は「社会保険料・追加控除」欄でON/OFFできますが、扶養控除・iDeCoの掛金控除などは考慮していません。実際の税額とは差異が生じるため、正式な判断には税理士等にご確認ください。
- 社会保険料(健康保険・介護保険料等)は、実際の等級表や自治体・保険者ごとの料率ではなく、給与に対する概算料率(現役時代)・年額の直接入力(退職後)という簡易的な近似です。配偶者控除は配偶者特別控除(配偶者の合計所得金額48万円超133万円以下で段階的に減る控除)に対応していません。
- 運用資産の利回りは(グライドパスを使う場合も年齢帯ごとに)一定率での複利計算です。市場変動リスクは反映していません。
- 年齢帯別の支出倍率・グライドパスの利回りは、年齢による決め打ちの想定です。実際の支出の推移や市場環境を予測するものではありません。
- 公的年金の繰上げ・繰下げ調整は増減率のみを反映した簡易計算です。在職老齢年金による支給停止、繰下げ待機中の他の収入との関係は考慮していません。60歳未満・75歳超の受給開始年齢を入力した場合は、制度の上下限(-24% / +84%)に丸めて計算します。
- 加給年金は配偶者加算のみの簡易計算です。子の加算、配偶者が65歳になった後の振替加算、在職老齢年金による支給停止は考慮していません。金額は年度改定されるため、既定値(40万8,100円)は概算値としてご自身で最新の値に調整してください。
- 遺族厚生年金は「max(死亡した人の老齢厚生年金額×3/4, (死亡した人+生存側自身の老齢厚生年金額の合計)×1/2) − 生存側自身の老齢厚生年金額」という併給調整の簡易計算です。中高齢寡婦加算(現行制度では妻のみが対象という性別非対称のルールで、このアプリは性別を管理していないため非対応)、65歳以降の受給調整の細部(経過的寡婦加算など)、遺族基礎年金(子のある配偶者・子のみが対象で、このアプリは子を考慮していないため非対応)、支給要件(保険料納付済期間など)の詳細判定は考慮していません(死亡した人ごとの「厚生年金加入期間が25年以上ある」チェックボックスのみで簡易的に判定)。死亡後の生活費は死亡前と変更せず試算するため、単身になった後の支出減少は反映されません。
- 現金保有目標は物価上昇に連動しない固定額です。
- 運用益課税について、譲渡損失の繰越控除、配当・分配金への課税、NISAの成長投資枠1,200万円の内枠、売却順序の最適化(銘柄選択)は考慮していません。元本割れ中の売却は損失として扱われるだけで、他の利益との損益通算や繰越はしません。
- グラフの点線(運用元本)は税引前の簿価です。
- パートナーの年金の課税計算・配偶者控除の判定には、「本人との年齢差」から求めたパートナーの実年齢を使用します(公的年金等控除は65歳以上/未満、配偶者控除は70歳以上で金額が変わります)。
- 保存先は**そのブラウザの `localStorage`**です。したがって保存した設定は、同じブラウザ・同じ配信元(同一オリジン)で開いたときにのみ復元されます。別のPCやブラウザ、シークレットウィンドウ、ファイルの置き場所を変えた場合は引き継がれません。ブラウザの履歴・サイトデータを削除すると保存内容も消えます。
- 補助的に、Claude.ai上で**Publish済みのアーティファクト**として開いた場合はアーティファクト永続ストレージ(`window.storage`)にも保存します(Free プランでは永続ストレージ自体が利用できません)。詳細は[Claude Help Center](https://support.claude.com/en/articles/9487310-what-are-artifacts-and-how-do-i-use-them)を参照してください。
- 長期的に残したい設定値は、念のため別途メモしておくことをおすすめします。
- 本ツールは個人の資産計画の参考情報を提供するものであり、投資助言・税務助言ではありません。
